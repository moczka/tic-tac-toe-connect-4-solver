# Getting Started:

Ensure the latest versions of `npm` and `node` are installed in your system.

1. Install package dependencies by running `npm install` in your terminal.
2. Mocha is used as the Testing Framework. Run `npm run test` to run Unit Tests for TicTacToe class.
